# BuildersLab

BuildersLab is a collaborative lab where students and early-career professionals work in teams to build and ship real-world AI, machine learning, and data science projects.

## What We Build
- Machine Learning
- AI Applications
- Data Science Projects

## Cohort Structure
- 4-month program
- Team-based collaboration
- Final portfolio-ready project
